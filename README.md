# مصنعي البسيط — Masnayi Simple

تطبيق أندرويد أوفلاين يعمل محليًا على الهاتف باستخدام WebView وlocalStorage.

## الوظائف
- وردية مفتوحة وإدخالات مستمرة وإغلاق وإعادة فتح للتعديل.
- خطوط الرخام 2 (MDB) و3 (MD) والخشب 2 و4 و5 و6.
- إنتاج كل خط وأكواد الرخام والأوزان ومتوسط وزن اللوح.
- إدخال الوزن شامل الفارغ أو الصافي (إنتاج 40 كجم، هالك 20 كجم).
- هالك مستقل لكل خط رخام وهالك مشترك للخشب.
- مؤقت مشاكل لكل خط، وإحصاءات الوردية.
- تصدير نسخة احتياطية JSON.

## إنشاء APK
ارفع محتويات هذا المجلد إلى مستودع GitHub جديد، الفرع main، ثم Actions > Build Masnayi Simple APK > Run workflow. بعد نجاح التشغيل نزّل artifact باسم Masnayi-Simple-APK.

## ملاحظات
- البيانات محلية داخل التطبيق فقط. حذف التطبيق أو مسح بياناته يحذف السجلات؛ احفظ نسخًا احتياطية بشكل دوري.
- نسخة أولى للتجربة. لا توجد مزامنة أو استيراد نسخة احتياطية حتى الآن.
- يجب اختبار التطبيق والحسابات على الجهاز قبل الاعتماد عليه في سجلات المصنع.
